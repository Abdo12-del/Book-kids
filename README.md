# مكتبة المبدعين الصغار

نسخة تفاعلية محلية لمعاينة المكتبة ومساحة الطفل والإدارة قبل بناء الخادم. تعتمد تجربة الكتاب على مكتبة `react-pageflip` المبنية على StPageFlip.

## التشغيل

```sh
npm install
npm run dev
npm run build
```

## تجربة رحلة القصة

1. اضغط «دخول المبدعين» واختر مساحة المبدع الصغير.
2. اكتب قصة واحفظها أو أرسلها للمراجعة.
3. عد إلى المكتبة، ثم اختر مساحة فريق المكتبة من شاشة الدخول. افتح القصة ووافق عليها وانشرها، أو اطلب تعديلاً وأضف ملاحظات.
4. ستظهر القصة المنشورة في المكتبة وكتاب المجلد الأول. يمكن إضافة تعليق عليها ثم مراجعته من لوحة الإدارة.

تُحفظ القصص والتعليقات وأعداد فتح القصص المنشورة في `localStorage` على الجهاز نفسه فقط. تُحسب القراءة مرة واحدة لكل جلسة متصفح في اليوم في هذه المعاينة. القصص الأولية أمثلة ثابتة، والإحصاءات تخص القصص المنشأة محلياً فقط. لا توجد حسابات حقيقية أو مصادقة أو عزل للصلاحيات في هذه النسخة، ويستطيع أي شخص على الجهاز فتح لوحة الإدارة. لا تستخدمها لجمع قصص الأطفال أو بياناتهم الحقيقية.

## قبل الإنتاج

يلزم بناء خادم وقاعدة بيانات دائمة، ومصادقة آمنة للطفل والإدارة وسياسات عزل، ومراجعة محتوى وحماية من الإساءة وتحديد معدل الطلبات، وتخزين الصور، وإدارة حقيقية للمجلدات والأطفال والصلاحيات، وتقسيم القصص الطويلة إلى صفحات، وإحصاءات موثوقة، واختبارات أمان وإمكانية وصول. يوجد مخطط أولي غير مطبّق في `supabase/migrations` للاسترشاد به؛ لم يُربط بالتطبيق ولا يُعد جاهزاً للنشر.

### محرك تقليب الكتاب

يستخدم القارئ [`@gullabs/react-flipbook`](https://github.com/gul-labs/flipbook)، وهو تطوير لـ StPageFlip يدعم اتجاه RTL، وانحناء الصفحات والظلال، والسحب على الهاتف، والتنقل بلوحة المفاتيح، وتقليل الحركة. اخترناه لأنه يعرض نص HTML عربياً قابلاً للتحديد بدلاً من تحويل صفحات القصص إلى صور. ترخيص واجهة React هو MIT، ومحرك `@gullabs/flipbook-core` هو MPL-2.0؛ راجع تراخيص الحزم عند التوزيع. المحرك تأثير صفحات HTML وليس نموذج WebGL ثلاثي الأبعاد كاملاً.
